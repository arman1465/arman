Система обнаружения дефектов на поверхности изделия
Проект компьютерного зрения для автоматического выявления дефектов на поверхности изделий, таких как трещины, пятна, сколы, царапины и другие визуальные аномалии.
Решение предназначено для задач контроля качества на производстве, где требуется быстро и стабильно находить дефектные участки на изображениях.

О проекте
Данная система анализирует изображения изделий и определяет наличие дефектов на поверхности.
В зависимости от выбранного подхода проект может решать одну или несколько задач:

Классификация: есть дефект / нет дефекта
Детекция объектов: поиск и локализация дефектов на изображении
Сегментация: выделение дефектных областей на пикселях
Аномалия-детекция: поиск отклонений от нормы без явной разметки всех типов дефектов
Проект может быть применён в промышленности для:

контроля качества на конвейере,
проверки металлических, пластиковых, стеклянных и других поверхностей,
автоматизации визуального инспекционного процесса.
Возможности
Обнаружение трещин, пятен, царапин и других дефектов
Обработка изображений с камеры, видеопотока или из набора файлов
Поддержка обучения модели на пользовательском датасете
Визуализация результатов на изображении
Оценка качества модели по метрикам
